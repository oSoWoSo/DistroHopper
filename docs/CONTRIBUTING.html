Contributing

We welcome contributions to Quickemu.

  • Help other Quickemu users by answering questions in the Quickemu Discussions 🛟
  • Improve the documentation in this README and the Quickemu Wiki 📖
  • File bug reports and feature requests in the Quickemu Issues 📁
  • Submit Quickemu Pull requests to fix bugs 🐞 or add new features ✨
    • Follow our guide to adding a new OS to quickget
    • Commit messages must conform to the Conventional Commits specification.
  • Sponsor the project 💖
